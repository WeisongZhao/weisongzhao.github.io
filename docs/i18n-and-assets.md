# Bilingual and asset conventions

## Current behavior

- English remains the default site and keeps its existing URLs.
- The language selector is one `inline-flex` component labelled `中文 / EN`.
- English pages remain in the project root; Chinese counterparts live under `/zh/`.
- The current language is rendered as non-clickable text, while the other language
  links to the counterpart of the current page.

Both versions are standalone static HTML. They do not require Jekyll, a local server,
or a JavaScript translation layer, and all pages can be opened directly in a browser.
The Chinese pages and reciprocal language links are generated by
`tools/generate_chinese_site.rb`; the generated HTML is committed with the site.

English content pages use semantic filenames such as `team.html`, `projects.html`,
`resources.html`, `publications.html`, and `gallery.html`. The former Bootstrap
template filenames have been removed.

## Media layout

All local visual assets live below `img/` and are grouped by purpose:

- `img/site/`: favicon and reusable interface graphics
- `img/home/`: home-page carousel and home-page feature media
- `img/team/`: principal investigator and team portraits
- `img/projects/`: project and open-source illustrations
- `img/publications/`: publication covers
- `img/gallery/`: gallery images, comparisons, and animations
- `img/news/`: news artwork

Use lowercase ASCII words separated with hyphens for new files. When renaming an
existing asset, update every source reference in the same commit and verify the built
site before publishing.
